# Contributing to Raccoon World

Until 1.0, Raccoon World does not accept pull requests from outside contributors: the design is still changing quickly. Issues are welcome, and so are private security reports ([SECURITY.md](SECURITY.md)).

Raccoon World is licensed under the [MIT License](LICENSE). Contributions are accepted under the MIT License: by opening a pull request you agree that your contribution is licensed under it, and you confirm that you have the right to license it so.

Read [AGENTS.md](AGENTS.md) for the repository rules; they apply to human and agent contributors alike.

## Issues

Search the existing issues first. Each issue has a native type (`Feature`, `Task` or `Bug`) and exactly one priority label: `P0`, `P1` or `P2`.

## Pull requests

- Reference the issue the pull request resolves, for example `Fixes #123`, and keep it to that one outcome.
- Report the commands you ran and their results.
- Never include credentials, secrets, personal data or private source in an issue, a pull request or a commit.

## Security

Report a suspected vulnerability privately, as [SECURITY.md](SECURITY.md) describes, never in a public issue or pull request.
